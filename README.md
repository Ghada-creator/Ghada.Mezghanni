# Portfolio de Ghada Mezghanni

Site statique en HTML et CSS, sans installation ni JavaScript.

## Ouvrir le site
Ouvrez `index.html` dans votre navigateur. Conservez `style.css` et le dossier `assets` à côté du fichier HTML.

## Publier sur GitHub Pages
1. Créez un dépôt GitHub.
2. Déposez le contenu de ce dossier à la racine du dépôt : index.html, style.css et assets (avec la photo et le CV).
3. Dans Settings → Pages, choisissez Deploy from a branch, puis main et / (root), et enregistrez.
4. GitHub affichera l’adresse du site après le déploiement.

Documentation officielle : https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Personnaliser
- Textes et liens : index.html.
- Couleurs, dimensions et mise en page : style.css, notamment les variables :root.
- Photo : assets/ghada.jpg.
- CV téléchargeable : assets/ghada-cv.pdf.

Nom affiché : Ghada Mezghanni, selon la demande. Le CV fourni conserve son orthographe d’origine, Ghada Mezghani.
Le contenu est adapté du CV fourni. Aucun chiffre d’audience, résultat commercial ou lien de réseau social n’a été inventé. Le CV ne donne pas l’URL du profil LinkedIn : ajoutez-la si vous souhaitez un lien.

Le site reprend la palette et la composition visuelle du site https://farah-dahmani.vercel.app/ avec une réalisation HTML/CSS originale. Il ne reproduit pas ses carrousels et animations JavaScript. La photo fournie est conservée avec son décor et intégrée dans un cadre arrondi.
